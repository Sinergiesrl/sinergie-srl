# Sinergie Premium — edizione ottimizzata

## Miglioramenti
- Nuove regole CSS di accessibilità e resa mobile in `sinergie-refinement.css`.
- Immagini JPEG ricompresse senza cambiare i nomi dei file.
- HTML impaginato riga per riga e navigazione mobile più robusta.
- SEO: dati strutturati Organization/BreadcrumbList, `robots.txt`, sitemap aggiornata.
- Precaricamento della fotografia hero, preconnessione ai font e lazy-loading delle altre fotografie.
- Palette oro e contenuti delle attività professionali conservati.

## PC
Estrai lo ZIP e apri `index.html`. Per un test realistico, meglio un server locale: `python -m http.server 8000` nella cartella, quindi http://localhost:8000/.

## GitHub Pages
Fai un backup del repository `sinergiesrl/sinergie-srl`, poi carica i file ESTRATTI dalla versione GitHub nella radice del branch pubblicato. Non caricare lo ZIP come file singolo. Verifica Settings > Pages e controlla il sito pubblico dopo il deploy.

## Verifiche ancora necessarie
Test visivi in browser reali, PageSpeed Insights, Search Console, privacy e correttezza delle attività pubblicizzate. I punteggi 10/10 non sono certificabili dal solo codice.
